VR / GODOT: the headset runs the visual-field task and, when supported by the hardware, records eye tracking (gaze, fixation, blinks, and saccades). This dashboard only receives and organizes those results; it does not run the test. The grid is exploratory: it displays detected/missed stimuli and is not equivalent to validated clinical perimetry. It does not calculate MD, PSD, or VFI. Gaze metrics depend on eye-tracker calibration and data quality.
