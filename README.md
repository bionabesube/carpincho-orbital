# carpincho-orbital

This project aims to monitor and assess the challenges posed by microgravity to astronauts during space missions. It is divided into two main components, each developed and maintained in its own branch within this repository.

- **`visor`**: Contains the foundations of a gamified application developed in **Godot**, designed to simulate an optical assessment through eye-tracking technology using virtual reality (VR) headsets. The application aims to evaluate visual capabilities by tracking eye position and collecting relevant data through interactive tasks.

- **`dashboard`**: Focuses on the post-processing, integration, and visualization of the collected data. It organizes and presents the acquired measurements to facilitate parameter analysis and interpretation. Additionally, it incorporates complementary data from other established monitoring devices to provide a more comprehensive assessment and support the final diagnostic process.

Each branch includes its own README with a more detailed explanation of its architecture, implementation, and functionality.
